# Media Tools kit, by Solnest AI

Installs the three free tools that Solnest's video, reel, caption and transcript skills run on, and proves each one works:

- **ffmpeg**: cuts, joins, converts and compresses video and audio.
- **Whisper** (whisper.cpp): turns speech into text, right on your computer. No account, no upload, no cost.
- **yt-dlp**: downloads a video from a link so Claude can work with it.

Skills that need it: content-studio, cinematic-director, real-estate-pics-to-video, remotion-loaded, hyperframes-pro, skill-video, the ad skills, and anything that makes captions or transcripts.

## What you need

- The Claude Code desktop app (or Claude Code in a terminal), on a Mac or Windows computer.
- Mac: Homebrew. Claude checks, and if it is missing, installing it asks for your Mac password once. Windows: winget, which comes with Windows 10 and 11.
- About 10 minutes and roughly 1 GB of disk space.
- No accounts, no keys, no cost. All three tools are free.

## Set it up in 3 steps

1. **Copy this page's link.**
2. **Paste it into Claude Code and say "set this up".** Claude installs the three tools, downloads a speech model, and proves it works: your computer makes a short spoken test clip and Whisper types it back.
3. **Try it:** give Claude a video or a voice memo and say "transcribe this".

Open the `solnest/media-tools-kit` folder in Claude Code and say **"check my media tools"** any time.

## Good to know

- **Updates install themselves.** Once a day, when Claude Code starts, the kit quietly moves to the newest release. You never have to ask.
- **An update never wipes your own things.** Your installed tools, your speech models, and any change you asked Claude to make to how this kit works stay exactly as they are.
- **Want it to work differently?** Just tell Claude ("always use the multilingual model"). It remembers.
- **Nothing leaves your computer.** Whisper runs on your machine. Your recordings are not uploaded anywhere.
